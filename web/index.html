Ask anything about a place.

Type a question in plain words. The agent writes QGIS code, runs it on real map data, checks the result and answers with a map. Name any city to start.

Answers come from OpenStreetMap and other open data, computed in QGIS. Data can be incomplete; check important results.

Which place?

A city, district or region anywhere in the world. Its map data is downloaded the first time (a few minutes), then reused.
